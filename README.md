## About

Full-stack developer and Informatics graduate (cum laude) from Universitas
Amikom Yogyakarta. I build clean, responsive web applications, from the
interface in React and Next.js to the API and data layer in PHP, Laravel,
and MySQL. I also build cross-platform mobile apps with Flutter and apply
machine learning to text data, such as sentiment analysis with Random Forest.

**Focus areas**
- Component-based UI development with React and Next.js
- Backend development with PHP and Laravel
- Mobile app development with Flutter
- Relational database design and query optimization with MySQL
- Data analysis and text classification with Python
